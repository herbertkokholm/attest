# Security Policy

## Supported Versions

attest is pre-1.0 and does not yet maintain separate release branches.
Security fixes are made against the latest version on `main`.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately via [GitHub's private vulnerability reporting](https://github.com/herbertkokholm/attest/security/advisories/new),
or by emailing thomas@herbertkokholm.dk.

Include as much detail as you can (affected code path, reproduction steps,
potential impact) so the report can be triaged quickly. You should expect an
initial response within a few days.
